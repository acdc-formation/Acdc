# ACDC SAAS OF — 3.20.47

## Objet
Correction ciblée de la page **Voir une entreprise**.

## Modifications
- La page **Voir une entreprise** reprend désormais la même disposition que **Modifier une entreprise**.
- Les champs sont affichés dans le même ordre logique et avec le même rendu de formulaire.
- Les champs sont verrouillés en lecture seule : aucune modification directe n’est possible depuis la page de consultation.
- Le bouton d’enregistrement est supprimé sur la vue consultation.
- Le bouton **Ajouter un contact** est désactivé sur la vue consultation.
- Les contacts annexes liés à l’entreprise sont repris dans le champ de consultation.
- Ajout d’un bouton **Modifier** pour basculer volontairement vers la fiche modifiable.
- Ajout d’un bouton **Retour** vers la liste des entreprises.

## Périmètre strict
- Intervention limitée à la page **Voir une entreprise**.
- Aucun changement volontaire sur le CRM.
- Aucun changement volontaire sur les modules situés au-dessus de la page Entreprises dans l’arborescence.
